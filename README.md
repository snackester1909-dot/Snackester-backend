# Node.js Auth Backend

A simple login/signup backend built with Express, MongoDB, and bcrypt.  
Deploy this directly from GitHub to Render.

## 🌐 Steps to Deploy
1. Push this code to your GitHub repo (example: `auth-backend`).
2. Create a MongoDB Atlas account → get connection string.
3. Go to [Render.com](https://render.com) → New → Web Service.
4. Connect your GitHub repo.
5. Add Environment Variables:
   - `PORT=10000`
   - `MONGO_URI=your MongoDB Atlas URI`
6. Deploy 🎉
